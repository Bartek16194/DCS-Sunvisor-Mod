## DCS: Visor Mod (2D Only)

Adds a functional sun visor to virtually every DCS module and community mod.
> **Note:** This mod currently supports **2D only**. I haven't found a practical way to make it work in VR yet.

## Installation
1. Download the latest release from the GitHub repository.
2. Open the **folder you just downloaded**.
3. Copy the **Mods** folder into your DCS Saved Games directory:
   - `C:\Users\<YourName>\Saved Games\DCS.openbeta`
   - or `C:\Users\<YourName>\Saved Games\DCS`

The final structure should look like:

Saved Games
└── DCS.openbeta
    └── Mods
        └── tech
            └── Sunvisor-Mod


## Mod Managers
This mod is fully with mod managers (JSGME, OMM, OvGME)

## In-Game Usage
Press the key bound to **Unlock View (Stop Padlock)** (default: **Num Lock**) to toggle the sun visor.
