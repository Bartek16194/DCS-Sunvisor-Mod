# DCS: Sun Visor Mod (2D Only)

Adds a functional sun visor to virtually every DCS World aircraft module and many community mods.

> [!NOTE]
> This mod currently supports **2D only**. I haven't found a practical way to make it work in VR yet.

## In-Game Usage

Press the key bound to **Unlock View (Stop Padlock)** (default: **Num Lock**) to toggle the sun visor.

## Installation

1. Download the latest release from:
   - https://github.com/Bartek16194/DCS-Sunvisor-Mod/releases/latest
2. Extract the downloaded archive.
3. Copy the **Mods** folder into your **Saved Games** directory:
   - `C:\Users\<YourName>\Saved Games\DCS.openbeta`
   - or
   - `C:\Users\<YourName>\Saved Games\DCS`

The final directory structure should look like this:

```text
Saved Games
└── DCS.openbeta
    └── Mods
        └── tech
            └── Sunvisor-Mod
```
